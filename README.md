# CourseScanner

Prototype iOS natif qui analyse localement et temporairement le flux ReplayKit pour repérer un montant affiché à l’écran. Aucun screenshot, enregistrement vidéo, texte OCR brut, restaurant ou destination n’est conservé.

Consultez [le guide de configuration](Docs/SETUP.md) avant d’ouvrir le projet dans Xcode.
